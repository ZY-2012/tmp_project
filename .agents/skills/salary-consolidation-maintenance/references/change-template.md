# 后续变更记录模板

按任务复杂度保留有用项，不要求每次都填写冗长表格。涉及密码、个人路径、公司账号和真实工资的内容只留在授权本地材料中。

## 需求与结果

- 用户请求：
- 触发条件与原行为：
- 修改后的行为（给一个输入/输出例子）：
- 本次主动改变的业务规则：
- 仍需沿用的输出约定：

## 实现与验证

- 基线提交 / 目标提交：
- 改动文件与原因：
- 测试环境、命令、结果与跳过原因：
- 同输入新旧七列/行数/金额/映射的对照结果：
- 界面流程与布局验证：
- 真实样本及整月覆盖范围：
- 未验证范围或剩余问题：

## 发布（本次需要时填写）

- 版本 / tag / 对应提交：
- Windows构建run：
- 打包EXE启动与相关功能验证：
- ZIP回下载、CRC及SHA256验证：
- 下载链接 / 源码链接：
- 技能参考文件是否需要同步：

## 给用户的简短交付

已完成〔具体行为〕。

下载/提交：〔实际链接〕。

验证：〔真正运行过的检查及结果〕。限制：〔影响本次判断的未验证范围〕。
