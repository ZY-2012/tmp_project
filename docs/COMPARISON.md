# v1.0 原工具与 v2.0 对照

对照对象：用户指定的 [v1.0/1.rar](https://github.com/ZY-2012/tmp_project/releases/download/v1.0/1.rar)，约82MiB，包含Windows EXE与PyInstaller构建文件，未包含源代码。

检查方法：读取打包配置、提取Python入口字节码并检查其函数和规则；在隔离工作目录加载原引擎，分别用同一加密样本及生成的演示表执行新旧引擎，回读Excel逐列比较。也在Linux显示环境重建原Tkinter界面，确认控件与操作入口。未在Linux运行Windows原EXE。

## 新旧引擎对照结果

- 用户提供的加密样本：七列数据及合计逐单元格一致。
- 原版的归一化匹配可匹配该样本的付款信息；新版补齐了第一轮实现缺少的这一行为。
- 生成演示数据：2个源文件、3个非明细汇总表、表头括号与空白变体、货币符号、文件名括号/横线/xls后缀差异、标题行映射、付款字段0和账号前导零；七列数据及合计一致。
- 34项测试覆盖业务规则、错误输入、源文件保护、原子保存、ZIP、路径偏好及桌面后台任务。
- 原始82MiB RAR使用新版解压函数与UnRAR后端完整展开，核对EXE大小一致。
- 桌面流程在显示环境中完成输入、后台执行、结果预览、密码清空；检查1160×850及1000×700布局。
- Windows构建流水线执行同一测试集，打包后实际启动EXE并验证Tk窗口初始化。

## 使用时需注意

归一化匹配会移除扩展名并容忍项目后缀。因此“同公司新增项目”可能复用较短公司映射，此行为兼容原工具，**仍应核对付款组织与发放账号**。新版在异常与待补映射页明确标记该情况。

RAR依赖系统后端；原RAR包已验证，不代表所有加密RAR/固实RAR和所有Windows后端组合均已验收。没有整月120份工资表，尚未进行整月金额基准回归。截图只使用生成的演示数据。
